# CRMEB 开发资料

这里集中维护项目开发资料，不存放商城运行数据。AI 开发入口是 [AGENTS.md](AGENTS.md)；人工查阅从本页按用途选择，不需要一次加载全部文件。

## 按用途查找

| 内容 | 入口 | 使用边界 |
| --- | --- | --- |
| 项目约定与任务路由 | [AGENTS.md](AGENTS.md) | 决定本次任务需要读取哪些规则和技能 |
| 开发规则 | [规则索引](AGENTS.md#规则索引crmebrules) | 架构、代码、数据库、安全、接口等强制约束 |
| 操作手册 | [技能索引](AGENTS.md#技能索引crmebskills) | 8 个专项技能，详细教程在各自 `references/` 中 |
| 专项角色 | [角色索引](AGENTS.md#子智能体索引crmebagents) | 架构检查、模块构建、路由校验的执行流程 |
| 各端补充约定 | [管理端](scopes/admin.md)、[移动端](scopes/uni-app.md) | 只在对应端任务中读取 |
| 项目说明 | [文档索引](../help/docs/文档索引.md) | 项目、架构、模块与运行说明，不代替当前规则或执行授权 |

## 目录布局

```text
.crmeb/
  AGENTS.md              AI 开发入口与统一规则索引
  README.md              人工查阅入口
  rules/                 当前开发规则
  skills/                8 个技能及按需加载的参考手册
  agents/                3 个专项角色说明
  scopes/                管理端、移动端补充约定
```

## 维护边界

- 强制约束只维护在 `rules/`；技能和角色引用规则，不重复定义。
- 技能入口说明选择条件与流程，详细契约和示例按需放在 `references/`。
- 项目说明维护在仓库根目录的 `help/docs/`；旧清单中的待办或完成标记不能代表当前系统状态。
- 密钥、机器专用配置、构建产物和会话临时文件不放进本目录。

## 校验

维护时核对索引、技能与角色的元信息、本地 Markdown 链接，以及已有入口是否指向正确真源。可选工具目录不要求创建；需要工具自动发现时，按 [AGENTS.md](AGENTS.md) 配置相应软链接。
