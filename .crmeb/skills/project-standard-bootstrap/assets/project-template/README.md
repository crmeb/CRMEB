# 项目入口

本仓库采用统一工程规范。项目业务介绍、真实技术栈和访问地址应在初始化后补充到本页。

## 快速开始

```bash
./run.sh doctor
./run.sh setup
./run.sh dev
./run.sh status
```

Windows PowerShell 使用对应的 `./run.ps1` 命令。标准命令的真实实现记录在 `.crmeb/project.json`。
