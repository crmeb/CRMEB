# 过程文档与测试索引

本目录同时承担两项职责：保存方案、决策、迁移记录和验收报告等过程文档，并提供测试统一索引。

```text
tests/
  README.md    本文件：过程文档导航 + 测试索引
  plans/       待评审、进行中的方案
  reports/     检查、验收、回归报告
```

过程文档顶部标注性质（待评审 / 已实施 / 已归档）与核对日期；已实施事实必须同步到正式文档或 `.crmeb/` 规则，过程记录不得冒充当前实现。失效后删除。

测试索引登记各应用的静态检查、单元、集成、契约、端到端和生命周期测试位置、命令、前置依赖与覆盖边界。测试脚本按端落位，本目录不存放测试脚本。
