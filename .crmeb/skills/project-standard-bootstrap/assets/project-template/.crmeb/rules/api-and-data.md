# API 与数据规则

- 请求校验、成功响应、错误码、分页、排序和过滤语义在项目内统一。
- 高风险写接口和回调必须具备幂等、权限和重放防护。
- OpenAPI/schema 等机器契约优先作为客户端类型和契约测试来源。
- 表、字段、金额、时间、状态、软删除和多租户语义统一；索引对应真实查询。
- 迁移只向前追加，已发布迁移不可回改；UPDATE/DELETE 必须有精确条件。
- 新安装 schema 与所有历史迁移的最终结果一致，破坏性变更有兼容窗口和恢复计划。
