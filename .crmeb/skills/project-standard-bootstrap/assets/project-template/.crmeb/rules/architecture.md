# 架构与目录规则

- AI 规则正文只维护在 `.crmeb/`。
- 后端业务代码位于 `backend/`，前端应用位于 `frontend/<应用名>/`。
- 模块公开入口和依赖方向必须明确；禁止跨模块引用内部实现或形成循环依赖。
- 领域逻辑不依赖 UI、Web 框架、数据库驱动或具体第三方 SDK。
- 共享代码只有存在两个以上真实消费者时才抽取，并具有明确所有者。
- 目录迁移必须同步 import、构建、测试、Docker、CI、部署和文档，并作为可回滚的独立变更。
