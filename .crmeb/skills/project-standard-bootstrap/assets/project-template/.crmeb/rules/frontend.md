# 前端规则

- 可独立构建的应用位于 `frontend/<应用名>/`，共享包通过 workspace 显式依赖。
- 页面负责场景编排，业务逻辑进入 service、store、hook 或 composable。
- 请求、响应、路由、组件属性和事件保持类型安全，并与 API 契约同步。
- 页面覆盖 loading、empty、error、无权限和成功反馈，危险操作必须确认。
- 使用设计令牌与共享组件，满足响应式、键盘操作和可访问名称要求。
- 构建变量不得承载秘密；发布物从锁定依赖的干净环境生成。
