# 全栈协作规则

- 从前端 API 函数追踪 request 封装、后端路由、Controller、Service、Repository 和 migration，不根据字段名猜实现。
- 前端校验负责体验，服务端负责安全校验、权限、所有权和业务不变量。
- 新增持久化字段同步 migration、Model、Service、API schema、前端类型、表单、列表、测试和升级包。
- 列表接口由后端分页、校验筛选和限制排序；数据库索引对应实际查询。
- 权限同步菜单、路由、中间件、角色数据和前端控制，隐藏按钮不能替代服务端鉴权。
- 手工改库只能用于经授权的临时诊断，正式交付必须通过可追踪迁移。
- 对不熟悉后端的协作者，用页面/API语言解释影响，提供真实路径和最小验证命令。
