# 文档规则

- `help/docs/` 描述当前项目事实，`.crmeb/` 维护 AI 规则和技能。
- `tests/` 保存方案、决策和验收过程，并提供测试统一入口；过程文档与测试索引同目录，不另建平行的过程文档目录。
- 同一事实只有一个权威正文，其他入口只摘要和链接。
- 命令写明执行目录、前置条件、成功信号和已验证环境。
- 代码、配置和可执行结果优先于旧文档；冲突时修正文档并记录证据。
- 新增或移动文档后检查链接、索引和易漂移事实。
- 后端及每个独立前端应用必须有就近 `README.md`，并链接到 `help/docs/applications/<应用ID>.md`；不能用一份总说明替代多个应用。
- 代码变更影响应用职责、版本、命令、配置、端口、路由/API、数据、构建或发布方式时，同一变更检查并更新对应应用说明；不影响时记录已检查无需更新。
