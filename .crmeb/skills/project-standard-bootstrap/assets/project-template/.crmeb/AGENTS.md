# 项目 AI 开发规范

本目录是项目 AI 规则唯一正文来源。根级工具入口只指向本文，不复制规则。

## 处理任务前

1. 读取 `.crmeb/project.json`，确认应用、服务、路径和标准命令。
2. 根据任务加载相关规则与技能，不整目录读取；改某端前先读该端技能的项目目录说明。
3. 检查 Git 状态，区分用户已有改动与本任务改动。
4. 从代码和配置核对事实，不把旧文档当作实现证据。

## 跨层协作

主要负责前端的开发者提出全栈需求时，先从前端 API 路径追踪到后端路由、业务层、数据访问和迁移。解释每层影响并给出真实文件位置；禁止用手工改数据库替代迁移，也不能因为前端隐藏按钮就省略服务端权限校验。

## 完成要求

执行项目契约中的 `check`、相关 `test`、必要 `build` 和 smoke。静态检查不等于运行验证；升级包未完成隔离升级测试时只能标记为候选。
