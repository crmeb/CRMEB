# CRMEB v8 项目文档中心

本文档目录面向产品、研发、测试、实施和运维人员，内容以当前仓库代码为依据，不以历史版本宣传材料代替实现事实。

## 文档基线

| 项目 | 内容 |
|---|---|
| 项目 | CRMEB v8 |
| 发布阶段 | 首版开发阶段；插件清单与 Installer 版本统一为 `1.0.0` |
| 文档检查分支 | `v8.0.dev`（本次核对快照，不限制后续开发分支） |
| 文档检查日期 | 2026-09-24 |
| 后端 | ThinkPHP 8、多应用模式、PHP 8.2-8.4 |
| 管理端 | Vue 3.5、Vue Router 4、Pinia 2、Element Plus 2.9、Vite 5（纯 JS） |
| 用户端 | uni-app 官方 CLI、Vue 3、Pinia 2、Vite 5，多端条件编译；源码在 `frontend/uni-app/src/` |
| 基础设施 | MySQL 5.7+（推荐 8.0）、Redis、Nginx、PHP-FPM、Workerman |

> 文档中的数量是本次检查时的快照。模块、路由、页面和数据表会随插件安装状态与后续开发变化，运行时状态应以数据库和代码为准。

## 文档维护约定

出现以下变更时，应在同一提交中更新对应文档：

| 代码变更 | 需更新文档 |
|---|---|
| 新增/删除模块或驱动 | `模块与驱动.md`、`项目功能.md` |
| `aiagent` 模块的功能、内置 Skill、业务工具、任务调度或依赖变化 | `AI Agent 模块.md` |
| 新增 API 或修改认证/响应 | `api/` 下对应文档 |
| `service_mcp` 模块的 MCP 工具清单或接入方式变化 | `api/MCP接口.md`、`AI Agent 模块.md`、根 `README.md`「连接本项目的 MCP 开发工具」 |
| 数据表、字段或迁移变化 | `数据库设计.md` |
| 新增后台进程、端口或部署依赖 | `项目架构.md`、`部署指南.md`、`运维手册.md` |
| 前端构建方式或环境版本变化 | `开发指南.md`、`部署指南.md` |
| 密钥、跨域、上传或权限策略变化 | `安全与配置.md` |

更新文档时请保留以下原则：

- 路径、命令和端口必须能在仓库中找到对应实现。
- 区分“代码具备”“模块已安装”“后台已配置”“生产已启用”四种状态。
- 不在文档中写入真实密码、AppSecret、私钥、访问令牌或用户数据。
- 业务接口明细以路由文件为最终事实来源；本文档提供稳定的分组和使用约定。
- 本目录的 Markdown 文件统一使用中文名称；改名时同步更新根 README、`.crmeb/` 和各端的引用。
- 本目录位于 `help/docs/`；文档中的代码路径和运行命令均相对仓库根目录，Markdown 链接相对当前文档。
- 开发规则与技能只维护在 [AI 开发入口](../../.crmeb/AGENTS.md)，本文档不复制强制规则正文。
- 已删除的专项支付、队列探针资料不再作为依赖；支付排障见运维手册，队列配置见部署指南。
- 提交前同时运行 `php think docs:check` 与 `node scripts/check-doc-facts.mjs`；前者检查文档结构与路径，后者校验易漂移的代码事实和根入口链接。
