# 安全与配置指南

> 核对日期：2026-09-14。本文描述配置与验收建议，不代表当前部署已经完成安全加固；强制要求见 [安全红线](../../.crmeb/rules/安全红线.md)。

## 1. 安全边界

系统涉及用户个人信息、订单、支付、退款、余额、积分、佣金、第三方密钥和文件上传，生产环境应按高敏感业务系统管理。

安全控制覆盖：

- 身份认证与会话；
- 管理员与接口权限；
- 数据访问与个人信息；
- 支付/退款回调；
- 文件上传与文件管理；
- 插件和驱动供应链；
- 密钥、配置、日志与备份；
- 网络、跨域和实时连接。

## 2. 密钥管理

不得提交或公开：

- `backend/.env` 中的数据库、Redis、应用密钥；
- 微信/支付宝/小程序/公众号 AppSecret；
- 支付私钥、证书和 API v3 密钥；
- 对象存储 AccessKey/Secret；
- 短信、邮件、机器人和物流服务密钥；
- 对外 API 的 appsecret 和访问令牌。
- AI 模型 API Key、MCP 服务密钥、外部工具连接中的 Authorization 和机器人 Webhook。

建议：

- 使用部署环境变量或密钥管理服务注入。
- 开发、测试、生产使用独立账号和密钥。
- 对已进入 Git 历史或前端产物的密钥立即轮换，删除当前文件并不能使旧密钥安全。
- 密钥设置负责人、用途、过期时间和轮换记录。
- 私钥文件权限仅授予运行账户，不放在 Web 根目录。

前端 `manifest.json` 和 JS 包对终端用户可见，不能保存真正需要保密的服务端凭证。

AI 开发工具的 MCP 连接配置属于本地开发配置，不是商城运行依赖。即使配置文件已经加入 `.gitignore`，Git 仍会跟踪此前入库的文件；退出跟踪也不能清除提交历史中的凭据，应独立处理凭据轮换。

## 3. 生产基础配置

- `APP_DEBUG=false`。
- 数据库调试关闭，不向响应输出 SQL/堆栈。
- 使用 Redis 缓存，启用认证并限制网络访问。
- 替换 Docker 示例中的所有默认密码。
- 修改系统文件管理开发密码，不使用源码默认值。
- 修改初始管理员账号密码并启用强密码策略。
- 生产数据库/Redis 不映射到公网。
- Nginx 仅暴露 `backend/public`。
- 全站 HTTPS，WebSocket 使用 WSS。
- 设置 HSTS、合理的安全头和 Cookie 属性。

## 4. 认证令牌

服务端依次支持自定义 `Authori-zation`、标准 `Authorization` 和请求参数 token。新客户端只应使用请求头：

```http
Authori-zation: Bearer <token>
```

安全要求：

- 不把 token 放 URL，避免进入访问日志、Referer 和监控。
- token 过期和注销时清除服务端缓存状态。
- 管理员、用户、客服和对外账号令牌类型不可混用。
- 多实例共享 JWT 密钥与 Redis，但缓存 key 按环境隔离。
- 管理端 Cookie 设置 `Secure`、合适的 `SameSite`，并评估 HttpOnly 策略与前端读取方式。
- 高风险操作增加二次确认、短期授权或操作审计。

## 5. 管理端权限

管理端写接口应经过：

1. CORS/预检处理；
2. 管理员 token 认证；
3. 角色/路由权限校验；
4. 管理操作日志。

安全检查：

- 新接口必须加入权限规则和菜单 API，不因前端隐藏按钮就认为安全。
- Controller 不能只根据请求中的管理员 ID 操作，应使用中间件注入身份。
- 超级管理员权限只分配给极少数账号。
- 文件管理、数据库备份、数据清理、在线升级、插件卸载属于高危权限。
- 定期审查离职账号、长期未登录账号和角色权限。

## 6. 用户端授权

- 游客接口不得返回其他用户的订单、地址、资产和消息。
- 所有按 ID 读取/修改资源的接口同时校验资源归属，防止 IDOR。
- 手机验证码实施手机号、IP、设备和时间维度限流。
- 登录/注册错误不应泄露账号是否存在的过多信息。
- 用户注销需校验身份、未完成订单/售后和资产处理规则。
- 小程序/公众号 OAuth code 只能在服务端交换，不信任前端传来的 openid/uid。

## 7. 对外 API

- appsecret 只在创建/重置时以受控方式展示，数据库使用安全哈希验证。
- 每个账号分配最小接口规则，默认拒绝未授权路由。
- 写接口实施 IP 白名单、频率限制、请求审计和业务幂等。
- 余额、积分、退款、发货等高风险操作设置单独权限和告警。
- 独立 `/api/mcp` 使用总开关 `mcp_enabled` 与账号密钥 `mcp_appkey` 等，经 `X-Mcp-Key` 或标准 `Authorization: Bearer` 认证，不复用开放平台凭据；完整接入见 [MCP 接口](api/MCP接口.md)。
- AI Agent 配置的 MCP/模型地址与工具参数需防 SSRF，写工具不能绕过确认、资源归属、业务幂等和审计。
- 对外推送 URL 防止 SSRF：限制协议、目标网段、重定向和 DNS 解析结果。
- 定期轮换 appsecret，支持旧 token 快速吊销。

## 8. 支付与退款

- 回调必须验证签名、商户身份、金额、币种和订单号。
- 不信任客户端“支付成功”状态。
- 支付和退款回调以业务单号幂等。
- 外部交易号与内部订单/退款单一一记录。
- 证书过期提前告警。
- 退款权限与普通订单编辑权限分离。
- 手工补单/补退款必须记录操作人、原因、外部凭证和复核人。
- `eb_refund_effect` 的副作用失败应可审计补偿，不可重复返还资产。

## 9. 文件上传与文件管理

上传：

- 校验扩展名、MIME、文件头和大小，不能只信客户端文件名。
- 图片重新编码或安全处理，防止伪造图片和元数据问题。
- 上传目录禁止执行 PHP/脚本。
- 用户文件使用不可预测名称，避免覆盖。
- 对象存储采用最小权限和短期上传凭证。
- 私有资料不要放公共 Bucket 或 `public/uploads`。

文件管理模块：

- 限制允许浏览和编辑的根路径。
- 规范化路径并防止 `../` 越界。
- 禁止编辑 `.env`、私钥、证书、Composer 自动加载和生产入口等敏感文件。
- 文件编辑 token 短期有效，并记录管理员与目标路径。
- 生产可考虑完全禁用在线文件编辑。

## 10. CORS 与网络

- 生产只允许明确的管理端/用户端域名，不使用任意 Origin + 凭证。
- 正确处理 OPTIONS，但预检放行不代表实际请求免认证。
- 信任代理头前配置可信代理列表，避免伪造客户端 IP。
- MySQL、Redis、PHP-FPM、Workerman 内部 Channel 只允许内网访问。
- WebSocket 校验 Origin、token 和 service，不允许客户端注册任意处理器。
- 限制 Nginx 请求体大小、连接数和敏感路径访问。

## 11. SQL 与数据访问

- 常规业务使用 Model/DAO 参数绑定，不拼接用户输入 SQL。
- 动态排序、字段名和表名使用白名单。
- Installer 执行 DDL 时不能接受未经验证的外部输入。
- 导出数据按角色和数据范围控制，并记录导出人和条件。
- 生产数据库账号不授予不必要的全局权限。
- 个人信息在日志、导出和客服页面按需脱敏。

## 12. 插件与驱动安全

安装扩展前审查：

- `plugin.json` 来源、版本、依赖和文件完整性；
- Installer 的 DDL、删表、文件写入和外部请求；
- 新路由认证与权限；
- 事件监听器是否修改资金/库存；
- 前端扩展是否加载远程脚本；
- 第三方 SDK 和 Composer/npm 依赖风险。

禁用模块后重启长驻进程，确认路由、事件、队列和 WebSocket 处理器均不再加载。卸载前备份并确认共享资源归属。

## 13. 日志与隐私

日志只记录排障所需最小信息：

- token 只记录不可逆摘要或末尾少量字符；
- 手机号、地址、姓名、身份证、银行卡脱敏；
- 请求体中的密码、验证码、appsecret 和支付密钥过滤；
- 异常响应不返回文件绝对路径、SQL 和堆栈给普通用户；
- 设置访问控制、保留周期和删除策略。

## 14. 依赖与供应链

- 使用锁文件和受控镜像源。
- 定期扫描 Composer/npm 依赖漏洞。
- 依赖升级先在隔离环境验证 PHP 8.2-8.4、Vue 3、Element Plus、Pinia 和 uni-app 各目标平台兼容性。
- 构建产物由 CI 生成并校验，不在生产服务器临时安装未知依赖。
- 第三方镜像固定版本或摘要，避免浮动标签引入未审查变化。

## 15. 上线安全清单

- 所有示例/默认密码已替换。
- 仓库历史中的真实密钥已轮换。
- Debug、SQL debug 和错误展示已关闭。
- 管理端、API、WebSocket 全部使用 HTTPS/WSS。
- CORS、可信代理和安全头已配置。
- 数据库/Redis/内部端口未暴露公网。
- 管理员和高危权限完成复核。
- 支付/退款回调验签、金额校验和幂等已验证。
- 上传不可执行，文件管理已限制或禁用。
- 插件/驱动清单检查通过。
- 备份加密且恢复演练完成。
- 日志脱敏、轮转、监控和告警已启用。
