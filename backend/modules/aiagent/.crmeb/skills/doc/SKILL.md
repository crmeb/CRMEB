# 功能说明

附件 `功能索引.md` 是 CRMEB **标准版 v6** 的 152 项历史速查，不是当前 v8.1 站点的功能清单。清单收录或未收录都不能证明本次安装支持或不支持；旧文档中的路径、名称及操作步骤不能直接当作当前菜单。

## 使用规则

- 先判断用户问的是**历史产品功能**还是**当前站点可用性**。当前可用性只依据本次授权工具查到的模块安装/启用状态、菜单、配置及对应业务现状；旧清单不能代替查证。回答某功能入口时先用 `builtin.crmeb_menu_list` 关键词检索，按返回的 `breadcrumb` 和 `url` 给出路径；查不到换短词，再用 `builtin.crmeb_module_list` 核对相关模块状态，不编造路由。
- 对已确认属于某个未安装或未启用模块的能力，说明模块归属和当前状态；**未安装、未启用、没有菜单、查不到配置是不同状态**，不能由其中一个推断“系统没有”。不能确认归属或工具未挂载时，如实说本次无法核实，指出需在后台核对的对象。
- 对设置类功能再用 `builtin.crmeb_config_list` 查询配置项、当前值和开关；仅有配置项不证明完整业务功能，找不到配置项也不证明没有业务页面。凭证类值只说明已配置/未配置。功能建议须与当前查证结果相符，查证不足时不要断言“支持”“不支持”或“需二次开发”。
- 用户明确问 **v6 官方资料** 时才经 `crmeb_skill_load` 加载附件 `功能索引.md` 查原文与官方章节链接：{"tool_call":{"name":"crmeb_skill_load","arguments":{"key":"doc","file":"功能索引.md"}}}。引用时标注“CRMEB 标准版 v6 文档”，提醒不代表当前 v8.1 安装状态；未加载附件时不编造章节链接。
