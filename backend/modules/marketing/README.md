# marketing/ — 营销玩法扩展模块

## 功能概述

营销玩法模块提供各类**独立运营活动**，这些活动不直接产生订单，而是在用户操作的关键节点（注册、支付、评价等）触发营销动作。每个子模块都是可插拔的插件包。

## 目录结构

```
marketing/
├── channel_code/    渠道码
├── lottery/         抽奖
├── newuser/         新人礼
└── signin/          签到
```

## 子模块说明

| 模块 | 目录 | 功能 |
|------|------|------|
| 渠道码 | `channel_code/` | 公众号渠道码生成、分类管理、扫码统计 |
| 抽奖 | `lottery/` | 九宫格/大转盘/翻牌等多种抽奖形式 |
| 新人礼 | `newuser/` | 新用户注册赠送余额/积分/优惠券 |
| 签到 | `signin/` | 连续签到/累计签到/积分奖励 |

> 直播功能已并入 `modules/channel/wechat_mini/`（微信小程序直播，**非独立插件**，作为小程序渠道内置功能：直播文件直接位于小程序模块下，建表与菜单由 wechat_mini 的 Installer 管理）。

## 设计原则

- 营销模块**不直接产生订单**，通过事件驱动与订单流程解耦
- 各子模块之间**不可互相引用**
- 通过 `event.php` 注册事件监听器，在用户操作节点触发营销逻辑
